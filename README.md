# Desafio Alura: Sorteador de Números 🎲

Este repositório contém a minha resolução do desafio do projeto **Sorteador de Números**, desenvolvido durante as aulas da Alura. O objetivo principal do projeto é praticar a lógica de programação em JavaScript, manipulando elementos do DOM (Document Object Model) e aplicando funções para sorteio randômico de valores.

## 🚀 Funcionalidades

- **Configuração de Intervalos:** O usuário pode definir a quantidade de números a serem sorteados, além do valor mínimo e máximo do intervalo.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação da página.
- **CSS3:** Estilização e layout do sorteador.
- **JavaScript (ES6):** Toda a lógica de sorteio, manipulação de arrays e controle de estado dos botões.

## 📂 Estrutura do Projeto

O projeto mantém uma estrutura simples de arquivos web:
- `index.html` — Interface principal do usuário.
- `style.css` — Design visuais e responsividade.
- `app.js` — Onde toda a mágica da lógica acontece.

> ⚠️ **Nota sobre Arquivos Ocultos:**
> O arquivo `.gitignore` deste projeto está configurado para ignorar o arquivo `testando.txt`, garantindo que rascunhos ou anotações locais de teste não sejam enviados para o repositório remoto.
